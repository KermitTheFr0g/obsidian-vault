# Project Vision
### Where do I see this project going? 
I want this to be something similar to Screeps where devs can continue to build and optimise systems to keep on top of the game. I want a semi feel of an idle game but being able to influence how your Guild operates by writing strong systems.

The current implementation of the game I think does feel quite linear, there definitely are different routes that a player can go and choose to automate. 

But I don't want the answer to the game being:
```python
while True:
	get_quests()
	start_quest()
	complete_quest()
	upgrade_hunter()
```

I want there to be much more depth to it.  

Another direction that I could take [[Dungeon Looters]] is turning it in to a training platform. Allowing players to learn how to code in a more enjoyable environment and also learn API vulnerabilities in the same place. 

The question here is do we have two different servers, or should the vulnerabilities be small enough that they aren't going to be game breaking but still give the user the ideas for the various methods they can try.
